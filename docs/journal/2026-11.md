## 2026-11-19 01:37 — the toolchain for no JavaScript is gone, and the epic log moved under docs/

[#6](https://github.com/GLODI-Engineering/spice-lsp/issues/6). What a visitor saw first was
mostly scaffolding: a 116 KB epic log at the repository root, an `extension/` directory holding
only a README, and a JavaScript toolchain — `package.json`, `pnpm-lock.yaml`,
`pnpm-workspace.yaml`, `biome.json` and a biome pre-commit hook — configured to lint and format
a TypeScript tree containing zero `.ts` files.

- `progress.core.yaml` is now `docs/progress.core.yaml`. Ten live references were repointed:
  `AGENTS.md`, `README.md` (two), `CHANGELOG.md`, `servers/core/README.md`,
  `servers/core/src/lib.rs` — which docs.rs renders — and four skills. The 2026-08 entry
  mentions the old path and was left alone; journal entries are history.
- `extension/` and the whole JS toolchain are removed, along with the biome hook and the
  TypeScript gate blocks in `AGENTS.md` and in the `implement-epic`, `test-and-progress`,
  `commit` and `fix-blocked` skills, which told an agent to run `pnpm` commands in a repository
  with no `package.json`. When an editor client is written here it arrives with its own
  toolchain in the same change, which is what the README's Status now says.
- The commit-convention scope list no longer offers `extension`.

One claim in the issue was wrong and worth recording: `node_modules/` was **not** committed.
`git ls-files | grep -c node_modules` returns 0 — the 55 MB directory is local, and
`.gitignore` has ignored it since the beginning. Only the configuration that produced it was
real.

Verification: `cargo fmt --all -- --check`, `cargo clippy --workspace --all-targets -- -D
warnings`, `cargo test --workspace` — 400 tests, unchanged by this commit, since nothing here
touches the crate.

Remaining from the issue: `docs/gotchas/INDEX.md` still renders "none yet". It is generated by a
pre-commit hook from the records in that directory, so it is empty because no gotcha has been
recorded, which is the truth rather than a defect.
